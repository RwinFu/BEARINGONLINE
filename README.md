# دفتر درخواست‌های برینگ آنلاین

پنل فارسی برای ثبت درخواست‌های تلفنی و سایت، چند قلم کالا، قیمت اعلامی، نرخ دلار، وضعیت و تاریخچه پیگیری. داده‌ها در SQLite روی سرور ذخیره می‌شوند؛ ورود درخواست‌های سایت خودکار نیست و در حال حاضر باید دستی ثبت شوند.

## اجرا

Node.js نسخه ۲۲.۵ یا بالاتر لازم است (ماژول `node:sqlite`).

```sh
npm install
APP_PASSWORD='یک-رمز-قوی' npm start
```

برنامه روی پورت 3000 یا مقدار `PORT` اجرا می‌شود. فایل پایگاه داده در `data/requests.sqlite` است. در محیط تولید `NODE_ENV=production` و `APP_PASSWORD` را حتماً تنظیم کنید؛ بدون رمز، برنامه فقط برای توسعه و آزمایش باز است. از HTTPS و یک میزبان با دیسک پایدار استفاده کنید. نشست‌ها با راه‌اندازی مجدد سرور از بین می‌روند. رمز مشترک برای دو کاربر است؛ حساب جداگانه و محدودیت تلاش ورود وجود ندارد، پس برای اینترنت عمومی از محافظ دسترسی و محدودیت تلاش ورود در میزبان استفاده کنید.

## پشتیبان

دکمه «دریافت پشتیبان» فایل JSON همه درخواست‌ها و پیگیری‌ها را دانلود می‌کند. برای دکمه «پشتیبان GitHub»، متغیرهای محیطی زیر را روی سرور تنظیم کنید:

- `GITHUB_TOKEN`: توکن با دسترسی Contents خواندن و نوشتن فقط برای مخزن خصوصی پشتیبان.
- `GITHUB_REPOSITORY`: نام مخزن به شکل `owner/repo`.
- `GITHUB_BRANCH`: شاخه موجود برای پشتیبان.

با هر کلیک، فایل `backups/requests.json` در شاخه تعیین‌شده به‌روزرسانی می‌شود. برنامه خصوصی بودن مخزن را بررسی می‌کند. پشتیبان‌گیری خودکار نیست؛ تاریخچه Git همچنان نسخه‌های قبلی و اطلاعات حساس را نگه می‌دارد. توکن را هرگز داخل کد یا مخزن قرار ندهید. فایل JSON برای بایگانی و بررسی است؛ بازیابی خودکار داخل پنل فعلاً پیاده‌سازی نشده است. از فایل SQLite و پشتیبان‌ها به‌طور منظم و امن نسخه‌برداری کنید.

تاریخ پیگیری با تاریخ‌نگار میلادی وارد و در جدول به شمسی نمایش داده می‌شود. قیمت و نرخ دلار به تومان هستند.

## پیش‌فاکتور

در فرم درخواست می‌توانید یک فایل PDF، JPG یا PNG تا ۱۰ مگابایت پیوست کنید. با وجود فایل، نام، شماره و کالاها اختیاری هستند و بعداً قابل ویرایش‌اند؛ بدون فایل، این اطلاعات همچنان الزامی‌اند. بارگذاری فایل جدید در یک درخواست، فایل قبلی را جایگزین می‌کند. اطلاعات از فایل به‌طور خودکار استخراج نمی‌شوند؛ برای جست‌وجوی نام و شماره باید آن‌ها را دستی وارد کنید. فایل‌ها در پایگاه داده ذخیره و به شکل Base64 در پشتیبان JSON گنجانده می‌شوند؛ با بزرگ شدن پشتیبان، محدودیت حجم API گیت‌هاب ممکن است مانع آپلود شود. پشتیبان‌ها حاوی اطلاعات محرمانه‌اند.
